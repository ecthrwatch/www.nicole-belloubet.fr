Errata — Corrections majeures de la version publique

Registre de transparence éditoriale

Cette page est un journal public, volontairement concis, des modifications majeures apportées au contenu de ce site — principalement des suppressions pour raisons de confidentialité, des corrections factuelles de matériel publié, et des remplacements significatifs de contenu dont les visiteurs devraient être informés. Les corrections de coquilles, les ajustements de mise en forme et les mises à jour de routine sont intentionnellement omis pour préserver l'utilité de cette page.

Pour l'historique complet, octet par octet, le HTML statique déployé de chaque langue est stocké dans un dépôt GitHub public :

  • Français (ce site) : https://github.com/ecthrwatch/fr.ecthrwatch.org
  • Anglais : https://github.com/ecthrwatch/www.ecthrwatch.org
  • Chinois : https://github.com/ecthrwatch/zh.ecthrwatch.org

Toute personne peut cloner ces dépôts et utiliser git log pour inspecter chaque commit. Lorsque le registre public a été délibérément modifié (par exemple, pour retirer une adresse e-mail privée qui s'est retrouvée par inadvertance dans une URL), ce fait est également documenté ici — afin que l'omission elle-même reste transparente.

Notes

Si vous avez constaté sur ce site un élément qui devrait selon vous figurer sur cette page errata et n'y est pas, veuillez prendre contact via la page À propos.

  • 2026-05-20 — Image principale corrigée — texte altéré par l'IA retiré (entrée avocat-épouse)

    ChatGPT, en assemblant l'image principale de l'entrée à partir de composants antérieurs, a altéré un fragment de texte à l'intérieur de l'image sans autorisation. Le texte altéré introduisait une attribution factuelle erronée. L'image a été remplacée par la version initialement prévue ; cette page documente en détail la chaîne des événements afin que le même type d'erreur soit plus facile à repérer — et plus facile à éviter — la prochaine fois.

  • 2026-05-18 — Nom d'utilisateur d'un courriel privé retiré de l'historique des URL

    Une migration de données back-end a brièvement intégré la partie locale d'une adresse de courriel personnelle dans un slug d'URL de `/people/` et `/parties/`. Le slug a été renommé dans la source ; l'historique git des dépôts de déploiement a été réécrit pour supprimer la chaîne de chaque commit.
